Visionneuse XPS Windows 11 : où est-elle passée ?

Vous cherchez la visionneuse XPS de Windows 11 et elle n'apparaît nulle part ? Ce n'est pas un bug de votre ordinateur. Microsoft ne l'installe plus par défaut depuis Windows 10 version 1803 : elle est devenue une fonctionnalité facultative, et la liste officielle des fonctionnalités supprimées de Windows la mentionne (support.microsoft.com/kb/4034825" rel="noopener">support.microsoft.com/kb/4034825).

Tenter de la réactiver

La méthode habituelle passe par les Paramètres, rubrique Système, puis Fonctionnalités facultatives : on y cherche « XPS Viewer » (ou « Visionneuse XPS ») pour l'ajouter. Les intitulés des boutons changent selon les versions de Windows ; vérifiez-les sur votre machine.

Si la fonctionnalité n'apparaît pas dans la liste, ou si l'installation échoue (message du type « n'a pas pu être ajoutée »), des utilisateurs signalent le cas sur les forums Microsoft. Inutile d'insister si vous voulez seulement lire un document.

Lire le fichier sans la visionneuse

  1. Ouvrez XPSRescue dans Edge, Chrome ou Firefox.
  2. Déposez le fichier .xps dans la zone prévue.
  3. Téléchargez le PDF, lisible avec n'importe quel lecteur.

Visionneuse ou conversion : que choisir ?

La visionneuse Microsoft permet de lire un XPS sans quitter Windows, mais seulement sur Windows et seulement si l'installation réussit. La conversion en PDF fonctionne aussi sur Mac, Chromebook et Linux, et le PDF se partage sans souci. En contrepartie, certains fichiers atypiques peuvent ne pas se convertir parfaitement.

Pour d'autres cas : ouvrir un fichier XPS (tous systèmes) ou ouvrir un fichier OXPS.

Bon à savoir : l'interface du convertisseur est en anglais. Le geste reste le même : glissez le fichier dans la zone « Drop a .xps file here ». Cet outil n'est pas affilié à Microsoft.

Questions fréquentes

Où trouver la visionneuse XPS dans Windows 11 ?

Elle n'est pas installée par défaut. Elle peut s'ajouter via Paramètres > Système > Fonctionnalités facultatives, selon votre version de Windows.

Pourquoi l'installation de la visionneuse XPS échoue-t-elle ?

Des utilisateurs rapportent que la fonctionnalité n'apparaît pas ou ne s'installe pas selon les versions. Il n'y a pas toujours de correctif simple ; la conversion en PDF est une solution de contournement.

Peut-on lire un XPS sans visionneuse ?

Oui : en le convertissant en PDF dans votre navigateur avec XPSRescue, sans rien installer.

La conversion donne-t-elle toujours un rendu parfait ?

Non. Certains fichiers inhabituels ou abîmés peuvent ne pas se convertir correctement.
