How to open an XPS file

An .xps file is a Microsoft XPS (XML Paper Specification) document — a fixed-layout format similar to PDF. The catch: Microsoft removed the XPS Viewer from Windows 10 and 11 (and it frequently refuses to re-install), while Macs, Chromebooks and Linux never had one. So a file someone sent you simply won't open.

The reliable fix on any device: convert the XPS to a PDF — which everything opens — right in your browser. Your file stays on your device, nothing is uploaded.

Open an XPS file in three steps

  1. Open XPSRescue in any browser.
  2. Drag the .xps (or .oxps) file onto the page, or click to choose it.
  3. In about a second you get a PDF you can read, print, or save.

On Windows 11 or 10

If the XPS Viewer is missing or "couldn't be added" as an optional feature, you don't need it — convert the file to PDF in the browser instead. See also XPS Viewer online.

On a Mac

macOS can't open .xps files on its own. The browser converter works the same in Safari or Chrome and gives you a PDF for Preview.

What about .oxps?

.oxps is the standardised OpenXPS version of the same format — it's supported too. See open an OXPS file, or convert XPS to PDF.
