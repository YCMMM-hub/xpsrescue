Come aprire un file XPS su qualsiasi dispositivo

Ti è arrivato un file .xps – una fattura, un estratto conto o una stampa fatta con la vecchia stampante «Microsoft XPS Document Writer» – e con il doppio clic non succede niente? È normale. L'XPS è un formato a pagina fissa simile al PDF, ma ormai pochissimi programmi lo leggono.

La soluzione più semplice, su qualunque dispositivo, è trasformarlo in PDF. XPSRescue lo fa direttamente nel browser e il file non viene inviato a nessun server: l'elaborazione avviene sul tuo dispositivo.

Apri subito il tuo file .xps: uno alla volta è gratis, senza account. Vai al convertitore

Tre passaggi per leggerlo

  1. Apri XPSRescue nel browser.
  2. Trascina il file .xps o .oxps sulla pagina, oppure clicca per sceglierlo.
  3. Scarica il PDF e aprilo con qualsiasi lettore.

A seconda del sistema

Windows 10 e 11

Da Windows 10 (versione 1803) il visualizzatore XPS non è più installato di default ed è diventato una funzionalità facoltativa, come indica Microsoft in support.microsoft.com/kb/4034825. Se vuoi solo leggere il documento, puoi saltare del tutto l'installazione e usare la conversione qui sotto.

Mac

macOS non include nessun programma per l'XPS. Apri XPSRescue in un browser aggiornato e leggi poi il PDF con Anteprima.

Smartphone

Il convertitore funziona nel browser in cui apri la pagina. Non l'abbiamo ancora provato sugli smartphone: l'unico modo per sapere se va sul tuo è tentare.

Chromebook e Linux

Anche qui manca un lettore XPS integrato; la conversione nel browser non richiede installazioni.

E se il file è .oxps?

È la variante normalizzata dello stesso formato, detta OpenXPS. XPSRescue accetta entrambe le estensioni, non serve rinominare nulla.

Da XPS a PDF

È proprio ciò che succede nei tre passaggi sopra: dal file XPS o OXPS esce un PDF da salvare, stampare o inoltrare. Non c'è conversione in Word o JPG.

Cosa è bene sapere

I file insoliti o danneggiati possono non convertirsi correttamente. Un file alla volta è gratuito, tutte le volte che vuoi. Per un'intera cartella c'è il Batch Pass: 9 € una tantum, senza abbonamento; il risultato è uno ZIP con tutti i PDF, senza mantenere la struttura delle cartelle.

Domande frequenti

Perché il mio file XPS non si apre su Windows 11?

Il visualizzatore XPS non è più installato di default nelle versioni recenti di Windows, e aggiungerlo come funzionalità facoltativa non sempre riesce. Convertire il file in PDF nel browser evita il problema.

Si può aprire un XPS su Mac?

Non direttamente: macOS non ha un programma per questo formato. Convertilo in PDF nel browser e aprilo con Anteprima.

Il mio file viene caricato su un server?

No. Con XPSRescue la conversione avviene nel tuo browser e il file resta sul tuo dispositivo.

È gratuito?

Un file alla volta è gratuito, senza account né filigrana. Per intere cartelle c'è il Batch Pass a 9 € una tantum.

Funziona anche con i file OXPS?

Sì, vengono accettate sia l'estensione .xps sia .oxps.
