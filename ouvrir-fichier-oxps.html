Ouvrir un fichier OXPS (OpenXPS)

Un fichier .oxps est un document OpenXPS. Si vous ne savez pas avec quoi l'ouvrir, c'est parce que très peu de logiciels le reconnaissent.

XPS et OXPS : quelle différence ?

OpenXPS est la version normalisée du format XPS de Microsoft (norme ECMA-388). Les deux ont la même vocation : un document à mise en page fixe, comme un PDF. L'extension .xps désigne le format Microsoft d'origine, .oxps la variante OpenXPS .

Un .oxps à ouvrir ? Convertissez-le en PDF dans le navigateur. Ouvrir le convertisseur

Convertir un fichier OXPS en PDF

  1. Ouvrez XPSRescue.
  2. Déposez le fichier .oxps (les deux extensions sont acceptées).
  3. Téléchargez le PDF et ouvrez-le comme n'importe quel PDF.

Le fichier reste sur votre appareil : la conversion se fait dans le navigateur.

Avec quoi l'ouvrir autrement ?

Sous Windows, la visionneuse XPS (si elle est installée) lit aussi ce format ; voir visionneuse XPS Windows 11. Sur Mac, il n'existe pas de lecteur intégré. Si votre fichier est un .xps classique, consultez ouvrir un fichier XPS.

Plusieurs fichiers OXPS ?

Un fichier à la fois est gratuit. Pour tout un dossier d'un coup, le Batch Pass (9 €, une fois) fournit un ZIP de PDF, sans arborescence de dossiers conservée.

Questions fréquentes

Qu'est-ce qu'un fichier OXPS ?

C'est un document au format OpenXPS, la version normalisée du XPS de Microsoft (ECMA-388), à mise en page fixe.

Avec quoi ouvrir un fichier .oxps ?

Avec la visionneuse XPS de Windows si elle est installée, ou en le convertissant en PDF dans le navigateur.

XPS et OXPS, est-ce la même chose ?

Ce sont deux variantes d'un même type de document ; XPSRescue accepte les deux extensions.

Le fichier OXPS est-il envoyé sur un serveur ?

Non, la conversion s'exécute dans votre navigateur.
