Open an OXPS file (OpenXPS)

An .oxps file is an OpenXPS document — the standardised (ECMA-388) version of Microsoft's XPS fixed-layout format. It's essentially the same as a .xps file, and the same problem applies: Windows 10 and 11 dropped the XPS Viewer, and Macs, Chromebooks and Linux never opened it.

Open it on any device by converting it to a PDF in your browser. Your file stays on your device — nothing is uploaded.

Three steps

  1. Open XPSRescue in any browser.
  2. Drag the .oxps (or .xps) file onto the page, or click to choose it.
  3. Download the PDF — read, print or archive it.

.oxps vs .xps

Both are the same family of fixed-layout documents; OpenXPS is just the open standard. XPSRescue handles both. Related: how to open an XPS file · convert XPS to PDF · XPS Viewer online.
