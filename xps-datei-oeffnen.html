XPS-Datei öffnen – so geht es auf jedem Gerät

Sie haben eine .xps-Datei bekommen – eine Rechnung, einen Kontoauszug oder einen Ausdruck vom alten „Microsoft XPS Document Writer“ – und ein Doppelklick bringt nichts? Das ist normal. XPS ist ein Format für Dokumente mit fester Seitenaufteilung, ähnlich wie PDF, aber kaum ein Programm kann es noch lesen.

Der einfachste Weg, unabhängig vom Gerät: die Datei in PDF umwandeln. XPSRescue erledigt das direkt im Browser. Die Datei wird dabei nicht an einen Server gesendet; die Verarbeitung findet auf Ihrem Gerät statt.

In drei Schritten zum lesbaren Dokument

  1. Rufen Sie XPSRescue im Browser auf.
  2. Ziehen Sie die .xps- oder .oxps-Datei auf die Seite oder wählen Sie sie per Klick aus.
  3. Laden Sie das fertige PDF herunter und öffnen Sie es mit einem beliebigen PDF-Programm.

Je nach Gerät

Windows 10 und 11

Der XPS-Viewer wird seit Windows 10, Version 1803, nicht mehr standardmäßig installiert; Microsoft führt ihn als optionales Feature (siehe support.microsoft.com/kb/4034825). Wenn Sie nur lesen wollen, was in der Datei steht, ersparen Sie sich das Nachinstallieren: Mehr dazu auf der Seite XPS-Viewer unter Windows 11.

Mac

macOS bringt kein Programm für XPS mit. Öffnen Sie XPSRescue in einem aktuellen Browser; das PDF können Sie danach in der Vorschau ansehen.

Android und iPhone

Der Konverter läuft im Browser, in dem Sie die Seite öffnen. Auf Smartphones haben wir ihn bisher nicht getestet – ob Ihr Gerät mitspielt, sehen Sie also nur durch Ausprobieren.

Chromebook und Linux

Hier gibt es ebenfalls keinen eingebauten XPS-Leser; die Umwandlung im Browser braucht keine Installation.

OXPS-Dateien: das gleiche Format in anderer Variante

Endet Ihre Datei auf .oxps, handelt es sich um die genormte Variante „OpenXPS“ desselben Formats. XPSRescue nimmt beide Endungen an, Sie müssen nichts umbenennen.

XPS in PDF umwandeln

Genau das passiert in den drei Schritten oben: Aus der XPS- oder OXPS-Datei entsteht ein PDF, das Sie speichern, drucken oder weitergeben können. Eine Umwandlung in Word oder JPG gibt es nicht.

Was Sie wissen sollten

Ungewöhnliche oder beschädigte Dateien lassen sich unter Umständen nicht sauber umwandeln. Eine einzelne Datei ist gratis, so oft Sie möchten. Wer einen ganzen Ordner auf einmal braucht, kauft den Batch Pass: 9 € einmalig, kein Abo. Das Ergebnis ist ein ZIP mit allen PDFs – flach, die Ordnerstruktur bleibt nicht erhalten.

Häufige Fragen

Warum lässt sich meine XPS-Datei unter Windows 11 nicht öffnen?

Der XPS-Viewer ist bei aktuellem Windows nicht mehr von Haus aus dabei, und das nachträgliche Hinzufügen als optionales Feature klappt nicht immer. Die Umwandlung in PDF im Browser umgeht das Problem.

Kann ich eine XPS-Datei auf dem Mac öffnen?

Nicht direkt, macOS hat dafür kein Programm. Wandeln Sie die Datei im Browser in PDF um und öffnen Sie sie dann in der Vorschau.

Wird meine Datei hochgeladen?

Nein. Bei XPSRescue läuft die Umwandlung in Ihrem Browser, die Datei bleibt auf Ihrem Gerät.

Ist das kostenlos?

Eine Datei nach der anderen ist kostenlos, ohne Konto und ohne Wasserzeichen. Für ganze Ordner gibt es den Batch Pass für 9 € einmalig.

Kann ich auch OXPS-Dateien öffnen?

Ja, die Endungen .xps und .oxps werden beide angenommen.
