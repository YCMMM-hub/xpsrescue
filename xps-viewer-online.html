XPS Viewer online — open XPS without the Windows viewer

The XPS Viewer used to ship with Windows, but Microsoft removed it from Windows 10 and 11. Re-adding it as an optional feature often fails with a "couldn't be added" error — and it was never available on Mac, Chromebook or Linux. So you're left with a .xps file and no way to open it.

You don't need the viewer. Open the file online, in your browser: XPSRescue converts it to a PDF you can view, print and keep. Your file never leaves your device.

How it works

  1. Open XPSRescue — no download.
  2. Drag the .xps file onto the page, or click to pick it.
  3. A PDF opens in your browser's built-in viewer. Save it if you want to keep it.

Why not just reinstall the XPS Viewer?

You can try (Settings → Optional features → Add a feature → "XPS Viewer"), but many people hit install errors, and it only helps on that one Windows PC. Converting to PDF works everywhere and leaves you a file any device can open. Related: how to open an XPS file · convert XPS to PDF.
